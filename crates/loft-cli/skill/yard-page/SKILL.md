# The Yard page

Run exactly `loft yard page` once, from the working tree, with no options: it needs no caller,
so give it no `--host`, `--session` or other identity, unlike the other `loft yard` commands.
Give the person the words it prints as they are, the address included. Add nothing to them, and
run nothing more.

Where it gives no address, because no page server runs or because one runs but does not serve
this tree yet, give the person those words as they are too, and run nothing more: start no page
server yourself.
